# Estratégia de Versionamento

## Repositório

GitHub: https://github.com/leomc06/sistemapedidosrestaurante

## Branches

- `main`: versão integrada do projeto.
- `feat/*`: implementação de funcionalidades.
- `test/*`: ajustes e criação de testes.
- `docs/*`: documentação.

## Commits

Foi usada uma convenção simples:

- `feat:` para funcionalidades.
- `test:` para testes.
- `docs:` para documentação.
- `chore:` para configuração e estrutura.

## Evidências

O histórico do repositório mostra criação da estrutura inicial, modelagem do domínio, testes unitários e integração por merge. A ideia é manter commits pequenos, com mensagens objetivas e relacionados à evolução incremental do trabalho.
